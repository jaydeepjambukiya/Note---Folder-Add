# 📒 Note App (Note-Folder-Add)

Live Demo ➤ https://note-felix.netlify.app/  
Source Code ➤ https://github.com/jaydeepjambukiya/Note---Folder-Add

---

## 🚀 About

A simple and intuitive **Note Taking App** where users can:
- Create folders
- Add and organize notes inside folders
- Edit and delete notes
- Navigate between folders and notes easily

Built with modern web technologies and deployed on Netlify.

---

## 🛠️ Features

✔ Create, Edit & Delete Notes  
✔ Organize Notes into Folders  
✔ Clean User Interface  
✔ Responsive layout  
✔ Local Storage Support (no backend required)

---

## 📦 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Local Storage
- Netlify (Deployment)
